> `lombokalgoritma/crypto` subpath — and their equivalents in every port — are **deprecated** and will be

## Quick start

### TypeScript

```ts
import { timsort, binarySearch, levenshtein, kmpSearch, HyperLogLog } from 'lombokalgoritma';
import { xxHash32 } from 'lombokalgoritma/string';
import { crt, isPrime } from 'lombokalgoritma/math';

timsort(['banana', 'fig', 'apple', 'kiwi'], (a, b) => a.length - b.length); // stable → ['fig','kiwi','apple','banana']
binarySearch([1, 3, 5, 7, 9], 7);   // 3
levenshtein('kitten', 'sitting');   // 3
kmpSearch('abcabcabc', 'abc');      // [0, 3, 6]
xxHash32('abc');                    // 0x32d153ff
crt([2n, 3n, 2n], [3n, 5n, 7n]);    // 23n
isPrime(2147483647n);               // true

const hll = new HyperLogLog(14);
for (let i = 0; i < 100_000; i++) hll.add(`x${i}`);
hll.count();                        // ≈ 100 000 (σ ≈ 0.8 %)
```

### Rust

```rust
use lombokalgoritma::{search::binary_search, sort::timsort_by, string::xxhash32};

let mut v = vec!["banana", "fig", "apple", "kiwi"];
timsort_by(&mut v, |a, b| a.len().cmp(&b.len()));
assert_eq!(v, ["fig", "kiwi", "apple", "banana"]);
assert_eq!(binary_search(&[1, 3, 5, 7], &5), Some(2));
assert_eq!(xxhash32(b"abc", 0), 0x32d1_53ff);
```

### Go

```go
import la "github.com/codinglombok/lombokalgoritma/go"

la.Timsort([]int{5, 3, 1, 4, 2})          // [1 2 3 4 5] (returns a sorted copy)
la.BinarySearch([]int{1, 3, 5, 7, 9}, 5)  // 2
la.Levenshtein("kitten", "sitting")       // 3
```

### Python

```python
from lombokalgoritma import quicksort, binary_search
from lombokalgoritma.string import xxhash32

quicksort([3, 1, 2], cmp=lambda a, b: b - a)  # [3, 2, 1]
binary_search([1, 3, 5], 5)                   # 2
xxhash32(b"abc")                              # 0x32D153FF
```

### PHP

```php
use LombokAlgoritma\Sort\Sort;
use LombokAlgoritma\String\StringAlgo;

Sort::mergesort([5, 3, 1, 4, 2]);             // [1, 2, 3, 4, 5]
StringAlgo::levenshtein('kitten', 'sitting'); // 3
StringAlgo::xxhash32('abc');                  // 0x32D153FF
```

## Repository layout (v0.1.1)

```
src/                          TypeScript reference (npm package `lombokalgoritma`)
tests/core/                   vitest suites (incl. regression.test.ts, vectors.test.ts)
tests/vectors/                shared JSON vectors (TypeScript runner; other ports from v0.2.0)
rust/                         Cargo workspace: lombokalgoritma (no_std+alloc) · -capi · -wasm
go/                           Go module github.com/codinglombok/lombokalgoritma/go (tags go/vX.Y.Z)
ports/python, ports/php       Python and PHP ports (manifests at repo root: pyproject.toml, composer.json)
ports/cpp, ports/perl, …      other ports (see the status table)
scripts/count_algorithms.ts   generates the Status section above
```

v0.2.0 moves every language to a top-level folder (`typescript/ rust/ python/ go/ php/ …`), adds
`vectors/lombokalgoritma-vectors-v1.json` with runners in five ports, and the normative
`docs/SPEC_LombokAlgoritma_v0.2.0.md`.

## Posting / Release Guide

Releases are cut by **release-please** from Conventional Commits on `main` (ADR-011: the version comes
from the git tag; only `feat`/`fix` touching published files bump it).

1. Merge PRs with Conventional Commit titles (`fix:`, `feat:`, `refactor!:` …).
2. release-please opens/updates one release PR per component; merging it creates the tags and GitHub releases.
3. The tag-triggered jobs in `publish.yml` run:

| Tag | Component | Registry |
|---|---|---|
| `v*` | TypeScript (`package.json`) | npm `lombokalgoritma` (with provenance) |
| `v*` | Python (`pyproject.toml`) | PyPI `lombokalgoritma` (trusted publishing) |
| `v*` | PHP (`composer.json`) | Packagist `codinglombok/lombokalgoritma` (update hook) |
| `rust-v*` | Rust workspace (`rust/`) | crates.io `lombokalgoritma`, `lombokalgoritma-capi`, `lombokalgoritma-wasm` |
| `go/v*` | Go module (`go/`) | proxy.golang.org / pkg.go.dev |

Required secrets: `NPM_TOKEN`, `CARGO_REGISTRY_TOKEN`, `PACKAGIST_USERNAME`, `PACKAGIST_TOKEN`;
PyPI uses OIDC trusted publishing (environment `pypi`).
