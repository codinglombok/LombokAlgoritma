> **v0.2.0 is a breaking release.** SHA-256, HMAC-SHA-256 and HKDF (and the `lombokalgoritma/crypto`
> subpath) were **removed from every port** — use
> [LombokEncryptDecrypt](https://github.com/codinglombok/LombokEncryptDecrypt) (ADR-016). Non-cryptographic
> hashes stay under `string/hash`: FNV-1a 32/64, MurmurHash3, xxHash32, xxHash64 (new), SipHash-2-4 (new).
> Errors now carry canonical codes (`INVALID_INPUT`, `OUT_OF_RANGE`, …). See [UPGRADE.md](UPGRADE.md).

## Quick start

### TypeScript

```ts
import { timsort, binarySearch, levenshtein, kmpSearch, HyperLogLog, dijkstra, tarjanScc } from 'lombokalgoritma';
import { xxHash64 } from 'lombokalgoritma/string';
import { crt, isPrime } from 'lombokalgoritma/math';

timsort(['banana', 'fig', 'apple', 'kiwi'], (a, b) => a.length - b.length); // stable → ['fig','kiwi','apple','banana']
binarySearch([1, 3, 5, 7, 9], 7);   // 3
levenshtein('kitten', 'sitting');   // 3
kmpSearch('😀a😀a', '😀a');          // [0, 2]  (code-point offsets)
xxHash64('');                       // 0xef46db3751d8e999n
crt([2n, 3n, 2n], [3n, 5n, 7n]);    // 23n
isPrime(2147483647n);               // true

const g = { nodes: 3, edges: [{ from: 0, to: 1, weight: 1 }, { from: 1, to: 2, weight: 2 }, { from: 2, to: 0, weight: 1 }] };
dijkstra(g, 0);                     // [0, 1, 3]
tarjanScc(g);                       // [[0, 1, 2]]

const hll = new HyperLogLog(14);
for (let i = 0; i < 100_000; i++) hll.add(`x${i}`);
hll.count();                        // ≈ 100 000 (σ ≈ 0.8 %)
```

### Rust

```rust
use lombokalgoritma::{graph::{dijkstra, Graph}, search::binary_search, sort::timsort_by, string::xxhash32, Error};

let g = Graph::from_triples(3, &[(0, 1, 1.0), (1, 2, 2.0), (0, 2, 5.0)]);
assert_eq!(dijkstra(&g, 0)?, vec![0.0, 1.0, 3.0]);
let mut v = vec!["banana", "fig", "apple", "kiwi"];
timsort_by(&mut v, |a, b| a.len().cmp(&b.len()));
assert_eq!(v, ["fig", "kiwi", "apple", "banana"]);
assert_eq!(binary_search(&[1, 3, 5, 7], &5), Some(2));
assert_eq!(xxhash32(b"abc", 0), 0x32d1_53ff);
assert_eq!(Error::OutOfRange.code(), "OUT_OF_RANGE");
```

### Go

```go
import la "github.com/codinglombok/lombokalgoritma/go"

la.Timsort([]int{5, 3, 1, 4, 2})          // [1 2 3 4 5] (returns a sorted copy)
la.BinarySearch([]int{1, 3, 5, 7, 9}, 5)  // 2
la.Levenshtein("kitten", "sitting")       // 3
la.XXHash32([]byte("abc"), 0)             // 0x32d153ff
```

### Python

```python
from lombokalgoritma import quicksort, binary_search
from lombokalgoritma.hash import xxhash32

quicksort([3, 1, 2], cmp=lambda a, b: b - a)  # [3, 2, 1]
binary_search([1, 3, 5], 5)                   # 2
xxhash32(b"abc")                              # 0x32D153FF
```

### PHP

```php
use LombokAlgoritma\Sort\Sort;
use LombokAlgoritma\String\StringAlgo;
use LombokAlgoritma\Hash\XxHash32;

Sort::mergesort([5, 3, 1, 4, 2]);             // [1, 2, 3, 4, 5]
StringAlgo::levenshtein('kitten', 'sitting'); // 3
XxHash32::hash('abc');                        // 0x32D153FF
```

```

python/                       PyPI package `lombokalgoritma` (pyproject.toml inside)
```

Graph and geometry algorithms live in one file per algorithm in every conformant port
(e.g. `typescript/src/graph/dijkstra.ts`, `rust/lombokalgoritma/src/graph/dijkstra.rs`, `go/graph_dijkstra.go`,
`python/lombokalgoritma/graph/dijkstra.py`, `php/src/LombokAlgoritma/Graph/Dijkstra.php`).

## Conformance (shared vectors)

```bash
cd typescript && npm run vectors:run                                  # → out/typescript.txt
(cd rust && cargo run -q -p lombokalgoritma-vectors -- ../vectors/lombokalgoritma-vectors-v1.json > ../out/rust.txt)
PYTHONPATH=python python -m lombokalgoritma._vectors vectors/lombokalgoritma-vectors-v1.json > out/python.txt
(cd go && go run ./cmd/vectors ../vectors/lombokalgoritma-vectors-v1.json > ../out/go.txt)
php php/bin/vectors.php vectors/lombokalgoritma-vectors-v1.json > out/php.txt
sha256sum out/*.txt                                                   # five identical hashes
```

## Posting / Release Guide

Releases are cut by **release-please** from Conventional Commits on `main` (ADR-011: the version comes
from the git tag).

1. Merge PRs with Conventional Commit titles (`fix:`, `feat:`, `refactor!:` …).
2. release-please opens/updates one release PR per component; merging it creates the tags and GitHub releases.
3. `release-please.yml` then calls the reusable `publish.yml`:

| Tag | Component | Registry |
|---|---|---|
| `v*` | TypeScript (`typescript/package.json`) | npm `lombokalgoritma` (with provenance) |
| `v*` | Python (`python/pyproject.toml`) | PyPI `lombokalgoritma` (trusted publishing) |
| `v*` | PHP (`composer.json`) | Packagist `codinglombok/lombokalgoritma` (update hook) |
| `rust-v*` | Rust workspace (`rust/`) | crates.io `lombokalgoritma`, `lombokalgoritma-capi`, `lombokalgoritma-wasm` |
| `go/v*` | Go module (`go/`) | proxy.golang.org / pkg.go.dev |

Required secrets: `NPM_TOKEN`, `CARGO_REGISTRY_TOKEN`, `PACKAGIST_USERNAME`, `PACKAGIST_TOKEN`;
PyPI uses OIDC trusted publishing (environment `pypi`).

LombokSimHash, LombokTableSheet, LombokLeiden and LombokGraphDB (SCC, Prim, Bellman–Ford, Dinic,
bipartite matching since v0.2.0). Cryptography lives in
[LombokEncryptDecrypt](https://github.com/codinglombok/LombokEncryptDecrypt) (ADR-016).
