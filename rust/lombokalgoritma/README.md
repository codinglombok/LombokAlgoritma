# lombokalgoritma (Rust)

Rust port of [LombokAlgoritma](https://github.com/codinglombok/LombokAlgoritma).
`#![no_std]` + `alloc`; the `std` feature is enabled by default.

```toml
[dependencies]
lombokalgoritma = "0.1"                                             # std
lombokalgoritma = { version = "0.1", default-features = false }     # no_std + alloc
```
